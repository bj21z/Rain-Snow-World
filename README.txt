雨雪秘境 2.1 稳定版
====================

项目结构：
index.html
audio/
  rain_light.mp3
  rain_heavy.mp3
  snow_wind.mp3
  thunder.mp3
  fireplace.mp3
  ambient_soft.mp3

本地打开：
1. 不要单独移动 index.html。
2. 保持 index.html 与 audio 文件夹在同一级目录。
3. 用 Safari、Chrome 或 Code App 预览 index.html。
4. 第一次播放时点击“开启声音”。

上传 GitHub：
1. 仓库根目录放 index.html。
2. 仓库根目录同时放 audio 文件夹。
3. audio 内必须保留全部 6 个 mp3。
4. 提交到 main 分支。
5. Cloudflare Pages 等待自动部署。

如果页面有画面但没有声音：
- 检查 audio 文件夹是否上传完整。
- 检查文件名是否完全一致。
- iPhone Safari 必须先点击“开启声音”。
